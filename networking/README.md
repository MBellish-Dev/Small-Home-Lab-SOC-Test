Networking

Networking is one of the supporting areas of the home lab.

Current Environment
- The lab currently operates on a single network connected to the home router.
- There are currently no VLANs or dedicated security segments.

EVE-NG
- EVE-NG is used as a dedicated networking laboratory.

Learning Goals
- Routing
- Switching
- VLANs
- Network troubleshooting
- Network security
- Network segmentation

Current Status
- The networking environment is still in the early stages of development.
- Future networking projects will be documented as they are completed.
