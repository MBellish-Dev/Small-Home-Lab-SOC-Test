Kali Linux

Purpose
- Kali Linux is the primary security testing and attack simulation system in the home lab.

Resources
- VM ID: 102
- vCPU: 2
- RAM: 2.19 GB
- Storage: 32 GB

Primary Uses
- Security testing
- Network reconnaissance
- Controlled attack simulations
- SOC detection exercises

Wazuh
- Kali Linux is connected to Wazuh as an agent so that security testing activity can be investigated from the defensive perspective.

Current Exercise
- The first documented exercise uses Nmap from Kali Linux to perform controlled reconnaissance against the Windows 11 VM.
